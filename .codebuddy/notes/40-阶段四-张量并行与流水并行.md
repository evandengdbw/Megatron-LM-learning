## A2. 线性代数基础

把 Y = XW 的 W（h×o）切 p 份：

- **列切（Column）**：W 沿输出维 o 切 → 各 rank 算 Y 的一部分，**输出零通信**，输入需完整
- **行切（Row）**：W 沿输入维 h 切 → X 也沿 h 切，各 rank 输出**部分和，需 all-reduce**

黄金组合（每层正好 2 次通信）：

```
hidden（完整）→ ColumnParallelLinear（QKV/FC1）  0 通信，输出切分
hidden（切分）→ RowParallelLinear（Proj/FC2）     1 次 all-reduce
```

SP 开启时两次 all-reduce 换成 reduce-scatter + all-gather（通信量不变，激活显存 1/p）。

### 1F1B（`:2147`）骨架

```
num_warmup = pp_size - pp_rank - 1
for i in range(num_warmup):               forward_step   # 填流水线
for i in range(n - num_warmup):  forward_step; backward_step   # 1F1B 稳态
for i in range(num_warmup):               backward_step  # 排空

bubble ≈ (p-1) / (n + p - 1)
```

本质：前向反向各只保留约 1 份在途激活（对比 GPipe 的 n 份）。

### VPP / interleaved（`:1019`）

每 GPU 持 vpp 个不连续层段；microbatch 按 `get_pp_rank_microbatches:929` 奇偶轮换 chunk 顺序。代价 P2P ×vpp，bubble 缩小到约 (p-1)/(vpp·n)。
