## 3. 术语表

| 术语 | 含义 |
|---|---|
| TP / SP | Tensor / Sequence Parallel |
| PP / VPP | Pipeline / Virtual Pipeline Parallel |
| DP / CP / EP / ETP | Data / Context / Expert / Expert-Tensor Parallel |
| 1F1B | one-forward-one-backward 流水调度 |
| dgrad / wgrad | 输入梯度 / 权重梯度 |
| AR / AG / RS | all-reduce / all-gather / reduce-scatter |
| main_grad | DDP 连续梯度缓冲中的 fp32 梯度 |
| THD | packed sequence 布局 (total_tokens, heads, dim) |
| cu_seqlens | varlen attention 累计序列长度 |
| GQA / MLA / MTP | grouped-query / multi-latent / multi-token prediction |
| aux loss | MoE 负载均衡辅助损失 |
| DistOpt | DistributedOptimizer（ZeRO-1 式分片） |
| TE / DCP | TransformerEngine / torch.distributed.checkpoint |
| GTP | Generalized Tensor Parallelism（实验特性） |
