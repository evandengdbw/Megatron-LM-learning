## 1. `distributed/` 目录

| 路径 | 职责 |
|---|---|
| **`distributed_data_parallel.py`** | Megatron 自研 DDP |
| **`param_and_grad_buffer.py`** | 梯度桶（连续内存） |

自研 DDP 的三个理由：梯度桶直接就是优化器 main_grad（省一份显存）；bucket 级 hook 实现反向与通信重叠；桶可按 DP 组 reduce-scatter（ZeRO-1 基础）。

## 7. `DistributedOptimizer`（`distrib_optimizer.py:113`）

| 行号 | 符号 |
|---|---|
| `:78` | `Range(start, end)`（DP rank 负责的参数区间） |
| **`:2765`** | `_copy_model_grads_to_main_grads`（**reduce-scatter** 而非 AR） |
| `:2811` | `_copy_main_params_to_model_params`（分片更新后 **all-gather**） |
| `:3177` | `step_with_ready_grads` |

```
桶按 DP rank 均匀切片（配 partition_buckets:1704）：
  RS 后 rank i 只拿第 i 片完整梯度       ← 带宽是 AR 的一半
  rank i 只对第 i 片持 fp32 状态并 step   ← 显存 1/dp
  AG 更新后的分片 → 所有人拿完整参数
通信量 RS(N)+AG(N) 与 AR(2N) 持平，fp32 状态显存除以 dp
```

工厂决策树（`__init__.py:1004`）：`use_distributed_optimizer` → DistOpt；fp16 → Float16OptimizerWithFloat16Params；else → FP32；混合 → Chained。
