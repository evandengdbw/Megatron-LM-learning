## A2. .bin/.idx 格式（`datasets/readme.md:18-31`）

```
{prefix}.bin：裸 token 流（dtype 在 idx 里）
{prefix}.idx：
  header    魔数 b"MMIDIDX\x00\x00"(:54) + version(u64) + dtype(u8)，共 34 字节(:263)
  dataset   sequence_count(u64), document_count(u64)
  sequence  lengths(int32×N), pointers(int64×N)
  document  indices(int64×D+1)
  可选      modes(int8×N)（多模态）
```

三层结构：document（以 EOD 结尾）→ sequence（定长切片）→ sample（连续 sequences + 自回归 shift）。

# Part B：分布式检查点

## B1. 设计思想

传统：每 rank 一个 `mp_rank_{tp:02d}_{pp:03d}/model_optim_rng.pt`，换并行度必须转格式。
MCore：以**全局视角描述张量**（`ShardedTensor`），strategy 决定落盘方式。**训练 TP=8、加载 TP=4 直接可用**。
