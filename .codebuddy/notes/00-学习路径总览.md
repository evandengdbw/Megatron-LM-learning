# Megatron-LM 学习路径总览

> 行号基于 `main` 分支实测。当前工作区若在 `core_r0.19.x`，行号平移表见 `91-分支差异核对.md`。
> `$ROOT` = 仓库根目录。

## 1. 两层架构

| 层 | 路径 | 定位 |
|---|---|---|
| Megatron Core（库） | `megatron/core/` | 可复用并行训练库，配置驱动、无全局状态 |
| Megatron-LM（训练框架） | `megatron/training/` + 根目录 `pretrain_*.py` | 参考训练脚本，依赖全局 `args`/`timers` |

核心心智模型：

```
pretrain_gpt.py（用户脚本：数据、forward_step、loss）
    │
    ▼
training.py::pretrain()（框架编排）
    ├── initialize_megatron()        → 进程组、随机种子
    ├── setup_model_and_optimizer()  → 模型、DDP、优化器
    ├── build_..._data_iterators()   → 数据迭代器
    └── train() → train_step() → forward_backward_func()   ← 进入 megatron/core
                        │
                        ▼
        schedules.py → GPTModel → TransformerBlock → TransformerLayer
                        │
                        ▼
        tensor_parallel/layers.py（TP 线性层 + 通信）
```

## 4. 读码方法

- 大文件先拿目录再沿调用链读：`rg -n '^(def |class )' <file>`
- 测试是最好的用法文档：`tests/unit_tests/`（运行需 GPU + `torch.distributed.run`）
- 实验性代码初学跳过：GTP、CUDA Graph、OTel、`experimental_attention_variant/`、FP4/FP8
- 老式 `parallel_state.get_*_group()` 与新式 `pg_collection.tp` 并存是进行中的迁移，见 `AGENTS.md`
