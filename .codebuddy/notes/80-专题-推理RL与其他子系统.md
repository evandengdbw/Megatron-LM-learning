# 专题：推理 / RL / 后训练 / 其他子系统

## 1. 推理（`megatron/core/inference/`）

训练好的 MCore 模型的进程内推理引擎（static / dynamic 两种模式）。文档：`inference/README.md`；示例：`examples/inference/offline_inference.py`。

| 路径 | 职责 |
|---|---|
| `engines/` | `static.py`（同进程读训练权重）/ `dynamic.py`（detokenizer + server） |
| `text_generation_controllers/` | Simple / SFT / beam search 控制器 |
| `modeling/` | gpt/bert/mamba 的 forward 包装（KV cache 注入） |
| `tokenizers/` | tokenizer 动态加载 |
| `ammo/` | 量化导出（MXFP8） |

训练↔推理并行度切换：`megatron/core/resharding/`，基于 dist_checkpointing 的 `ShardedTensor`。训练侧胶水：`megatron/inference/utils.py`。

## 2. RL（`megatron/rl/`，29 文件）

原生 RL 后训练库（GRPO 等），rollout 与训练共用同一套并行架构。文档：`rl/README.md`、`docs/user-guide/features/megatron_rl.md`；入口：根目录 `train_rl.py`。

关键文件：`rollout_bank.py`（rollout 存取）、`sequence_packing_utils.py`、`agent/`、`server/`。与训练主循环的关系：`training.py:2686` 的 `has_rl_optimizer`。

## 3. 后训练（`megatron/post_training/`）

ModelOpt 驱动的量化 / 蒸馏 / 剪枝。入口：`model_builder.py` 的 `modelopt_gpt_hybrid_builder`（被根目录 `model_provider.py` 调用）。示例：`examples/post_training/modelopt/`。

## 4. 弹性化（`megatron/elastification/`）

Flextron：训练一次得到多个可裁剪子模型（宽度 / 深度 / MoE 专家数弹性）。入口：根目录 `pretrain_hybrid_flex.py`；核心：`flextron_config.py`、`flextron_elasticity_hooks.py`。

## 5. SSM / 混合架构（`megatron/core/ssm/`，49 文件）

Mamba/SSM 层 + 与 attention 混合的 Hybrid 模型。入口：根目录 `pretrain_hybrid.py`（`hybrid_builder` 按 `--spec` 与 `hybrid_layer_pattern` 组装）；`pretrain_mamba.py` 已弃用（runpy 转发）。文档：`docs/user-guide/hybrid-model-migration.md`。

## 6. 上下文并行（`megatron/core/context_parallel/`）

长序列 CP 的 Ring/Paged attention 变体。概念见笔记 20（`parallel_state.py:124-131`）。文档：`docs/user-guide/features/context_parallel.md`。

## 7. 多模态

`models/multimodal/`、`models/llava/`、`models/mimo/`；入口：根目录 `pretrain_vlm.py`；示例：`examples/multimodal/`。
并行特殊性：vision 与 LLM 各一套进程组 → `MultiModuleProcessGroupCollection`（`process_groups_config.py:718`）+ `rank_offset`（笔记 20）。

## 8. 其余 core 子系统

| 路径 | 职责 |
|---|---|
| `core/fusions/` | 融合核（bias_gelu、bias_dropout、rotary、swiglu 等） |
| `core/tokenizers/` | tokenizer（HF 兼容 + 原生），入口 `build_tokenizer` |
| `core/timers.py` | 训练计时器 |

| `core/packed_seq_params.py` | THD 打包参数 |
| `core/extensions/` | TransformerEngine 适配层 |
| `core/telemetry/` | 遥测 |
