## 1. 五个并行维度

| 缩写 | 切什么 | 通信量 | 典型规模 |
|---|---|---|---|
| TP | 权重矩阵行/列 | 极大（每层 2 次 all-reduce） | ≤8，限单节点 |
| PP | 按层切 | 小（只传 activation） | 跨节点 |
| DP | 按 batch 切 | 中（梯度 all-reduce） | 剩余全部 |
| CP | 按序列长度切 | 中（attention 内 all-gather K/V） | 长上下文 |
| EP | MoE expert 切 | 中（all-to-all） | MoE 专用 |

约束：`world_size = TP × PP × DP × CP × EP`。

## 2. `RankGenerator`（`parallel_state.py:465`）

把 world 看成多维张量，每个并行维度是一个轴；取某并行组 = 固定其他轴、沿该轴取线。

| 行号 | 成员/方法 | 说明 |
|---|---|---|
| `:468-478` | `__init__(tp, ep, dp, pp, cp, order, ...)` | |
| `:479-480` | `assert ep == 1 or cp == 1` | CP 只进默认 RankGenerator，EP 只进 expert RankGenerator → 两个实例 |
| `:489` | `world_size = tp*dp*pp*cp*ep*gtp_remat` | |
| `:502-509` | order 校验补全 | size=1 的维度可省略 |
| `:517` | `get_mask(order, token)` | token → 布尔 mask |
| `:532` | `get_ranks(token)` | 调 `generate_masked_orthogonal_rank_groups:269` |

### `order` 规则

默认 `order="tp-cp-ep-dp-pp"`（`initialize_model_parallel:616`）。**最左 = stride 最小 = rank 最相邻**，通信最重的维度放带宽最高的链路。

例：`tp=2, cp=1, ep=1, dp=2, pp=2`（world=8）：

```
rank:    0  1  2  3  4  5  6  7
tp_idx:  0  1  0  1  0  1  0  1
dp_idx:  0  0  1  1  0  0  1  1
pp_idx:  0  0  0  0  1  1  1  1

TP 组：[0,1] [2,3] [4,5] [6,7]   ← 相邻（NVLink 域）
DP 组：[0,2] [1,3] [4,6] [5,7]
PP 组：[0,4] [1,5] [2,6] [3,7]   ← stride 最大，可跨节点
```

常用 token：`'tp'`、`'dp'`、`'dp-cp'`（DistOpt 分片域）、`'tp-pp'`（= mp）、`'tp-cp'`。

### `ModelParallelConfig` 字段分组

| 组 | 代表字段 |
|---|---|
| 并行度 | `tensor_model_parallel_size`、`pipeline_model_parallel_size`、`context_parallel_size`、`expert_model_parallel_size`、`virtual_pipeline_model_parallel_size` |
| 序列并行 | `sequence_parallel` |

`grad_scale_func`、`finalize_model_grads_func` 等**函数字段**是 core 与 training 解耦的手段。
